Per-Alarm Volume Control

Set a gentle 20% for weekend mornings and a blaring 100% for workdays. Each alarm gets its own volume level, color-coded for instant recognition.

See volume at a glance: Blue = Quiet, Green = Medium, Orange = Loud, Red = Maximum. No more guessing which alarm is which.

Gradual Volume Wake-Up

Start quiet and slowly increase volume over 10-60 seconds. A gentle way to wake up without the jarring shock.
